## 📌 Project Overview

This project is an **end-to-end Power BI Financial Risk Analytics project** designed to analyze loan applications, loan amounts, applicant demographics, income, employment, credit scores, and loan defaults.

The project follows a complete analytics workflow:

> **Data Source → Data Flow → Data Transformation → Data Modeling → DAX → Interactive Dashboard → Business Insights**

The dashboard contains **3 interactive analytical pages** focused on loan performance, applicant profiles, and financial risk metrics.

---

## 🎯 Project Objectives

* 💰 Analyze loan amounts across different purposes.
* 👔 Compare income and default rates by employment type.
* 👥 Analyze loan behavior across different age groups.
* 📅 Identify yearly default trends.
* 💳 Analyze loan amounts by credit score category.
* 👤 Study applicant demographics and marital status.
* 🎓 Analyze loan distribution by education.
* 📈 Calculate Year-over-Year loan amount changes.
* ⚠️ Track Year-over-Year default loan amount changes.
* 📆 Perform YTD loan amount analysis.
* 💵 Identify financial risk patterns across income categories.
