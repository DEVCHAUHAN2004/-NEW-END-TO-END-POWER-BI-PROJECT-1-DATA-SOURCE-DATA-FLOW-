## 📌 Project Overview

This project is an **end-to-end Power BI financial risk analytics project** focused on analyzing **loan applications, loan amounts, applicant demographics, income, credit scores, and loan defaults**.

The project transforms raw loan-related data into an **interactive and business-focused Power BI dashboard** that helps analyze lending patterns, applicant profiles, and financial risk indicators.

The dashboard is divided into **three analytical pages**:

* 📊 **Loan Default & Overview**
* 👤 **Applicant Demographics & Financial Profile**
* 📈 **Financial Risk Metrics**

The project also includes analytical calculations using **DAX**, including **Year-over-Year (YoY)** and **Year-to-Date (YTD)** metrics.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze overall loan distribution and loan amounts.
* Understand loan amounts across different purposes.
* Analyze income across employment types.
* Identify default rates across employment categories.
* Compare average loan amounts across different age groups.
* Analyze yearly loan default trends.
* Study applicant demographics and financial characteristics.
* Analyze loan amounts based on credit score categories.
* Understand the relationship between age group and marital status.
* Analyze loan distribution based on education.
* Track Year-over-Year loan amount changes.
* Analyze Year-over-Year changes in default loan amounts.
* Perform YTD loan amount analysis.
* Identify financial risk patterns across income categories.

# 🧮 DAX & Analytical Measures

DAX was used to create calculated measures and perform business-oriented analysis.

### Examples of analytical calculations used in the project:

```DAX
YOY Loan Amount Change
```

Calculates the change in loan amount compared with the previous year.

```DAX
YOY Default Loan Amount Change
```

Tracks the year-over-year change in default-related loan amounts.

```DAX
YTD Loan Amount
```

Calculates the cumulative loan amount within the current year.

```DAX
Default Rate
```

Used to analyze the proportion of default cases across different categories.
