## 📌 Project Overview

This is an **End-to-End Power BI Financial Risk Analytics Project** focused on analyzing loan applications, loan amounts, applicant demographics, income, employment, credit scores, and loan defaults.

The project follows a complete workflow:

**Data Source → Data Flow → Data Transformation → Data Modeling → DAX → Interactive Dashboard**

---

## 🎯 Project Objectives

* Analyze loan distribution and loan amounts by purpose.
* Understand income across different employment types.
* Analyze default rates across employment categories.
* Compare loan amounts across different age groups.
* Analyze yearly default trends.
* Study applicant demographics and financial profiles.
* Analyze loan amounts by credit score category.
* Understand loan patterns by education and marital status.
* Track **YoY Loan Amount Change**.
* Track **YoY Default Loan Amount Change**.
* Perform **YTD Loan Amount Analysis**.

---

## 📊 Dashboard Pages

### 1️⃣ Loan Default & Overview

Provides an overview of the loan portfolio and default behavior.

**Key Analysis:**

* 💰 Loan Amount by Purpose
* 👔 Average Income by Employment Type
* ⚠️ Default Rate by Employment Type
* 👥 Average Loan Amount by Age Group
* 📅 Default Rate by Year

### 2️⃣ Applicant Demographics & Financial Profile

Analyzes the financial and demographic characteristics of applicants.

**Key Analysis:**

* 💳 Median Loan Amount by Credit Score Category
* 👥 Average Loan Amount by Age Group & Marital Status
* 📊 Loan Amount by Credit Score Category
* 🏠 Loan Amount by Mortgage & Dependents
* 🎓 Number of Loans by Education Type

### 3️⃣ Financial Risk Metrics

Focuses on time-based financial and risk analysis.

**Key Analysis:**

* 📈 YoY Loan Amount Change
* ⚠️ YoY Default Loan Amount Change
* 📅 YTD Loan Amount by Credit Score & Marital Status
* 💰 Income Category Analysis
